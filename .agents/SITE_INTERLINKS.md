# 站内互联

## 入口与跳转规则

- 作者头像、显示名、用户名、转帖者及引用作者：作者 ID 属于归档账号时进入站内账号页；其他作者打开 X 主页。未知身份不构造站内账号入口。
- 帖子时间和回复数据入口：进入 `/posts/<tweet_id>`。回复增加“查看上文”；引用卡片增加“查看归档”。转帖记录与原内容分别使用各自的帖子 ID。
- 帖子详情页目前仅占位：显示帖子 ID、返回按钮及 X 原帖入口。读取现有帖子 API 仅用于补充关联入口，不展示正文、媒体或完整会话串。已知转帖、回复、引用和归档来源提供相应链接；未归档或未登录时仍可打开 X。
- 原帖、X 转帖、翻译、账号 X 主页和媒体源外链保留，新窗口打开。站内链接在当前页打开，不把整张帖子卡片变为点击区域。
- 账号页增加“搜索该账号”“查看账号任务”“打开 X 主页”；补档明细的帖子 ID 进入站内占位页，另留 X 原帖入口。“查看补档任务”同时传入账号及补档任务名称。
- 搜索页使用 `q`、`account` URL 参数，明确显示当前范围，可保留关键词切换到全站搜索。账号范围指该账号观察到的归档内容，含其转帖；关键词搜索设置 `search_origin=true`，使转帖原文也参与匹配。
- 任务页使用 `q`、`account`、`status`、`page` URL 参数，保留关键词、账号、状态和分页。`page` 采用从 0 开始的索引，首屏省略此参数。任务详情的返回按钮走浏览器历史，直接打开且没有可返回历史时回到任务列表。
- 任务详情关联帖子提供站内入口和独立 X 外链，关联作者按归档情况跳转，另有账号任务入口。全站批量重试及清理历史只在全站任务视图展示，账号视图不展示这些全站操作。
- 主导航、移动底栏和移动抽屉的“媒体库”统一进入 `/media`，列出所有账号的媒体帖子。账号自身媒体仍由账号页的“媒体”分类进入，不再默认使用第一个账号。

## URL 与接口

路由按字符串解析查询参数，避免 JavaScript 数字解析丢失 X 长 ID 的精度。
中文、数字关键词及 `+`、`&` 等字符使用 URLSearchParams 编解码。未知任务状态、非法账号 ID、负数及非整数页码会被丢弃。
账号页分类由路由 hash 驱动；浏览器历史恢复分类。路由启用滚动恢复，覆盖主内容区和账号内容区。

`GET /api/task-center/tasks` 及 `GET /api/task-center/summary` 新增可选的
`observed_account_x_user_id`。列表、分页总数、状态统计和当前有效失败记录都按同一账号 ID 精确筛选。
不传参数时保持原来的全站行为；不新增数据库结构或环境变量。

## 验证

- `npm run build`：TypeScript 检查及 Vite 生产构建通过。
- `tests/test_api.py`、`tests/test_tasks.py`：52 项通过，含新增的账号范围、分页、统计及有效失败筛选测试。使用 `42` 与 `142` 验证账号范围不会因字符串包含关系混入其他账号。
- 临时 Node 断言：验证长账号 ID、数字和中文关键词、特殊字符、任务状态和分页，以及非法参数处理。
- 使用用户已运行的前端进行浏览器检查：帖子占位页与 X 入口、搜索提交保留长账号 ID、账号范围提示、任务状态筛选和全站入口均可见。浏览器未登录，真实归档内容和任务数据由接口测试验证，未完成登录后的全流程人工浏览。
- 没有启动、停止或重启前后端服务。运行中的后端需要由操作者加载包含新筛选参数的代码，账号任务接口才能生效。
